Các trang mua gói, kết quả, lịch sử và quản trị thanh toán đã được nối API trong bước trước. Các nhóm tài khoản, bộ thẻ, CSV, thư viện, học/ôn, luyện tập, sổ tay, thống kê, quản trị chủ đề/tài khoản/bộ mẫu/nhật ký đã có lời gọi API hoặc component/hook gọi thay. Các route chuyển hướng và trang giới thiệu/chính sách/hướng dẫn/UI kit không cần API dữ liệu nghiệp vụ.

## Phân biệt dữ liệu frontend và nhà cung cấp

Frontend không còn trả điểm/nội dung mẫu cho 9 trang trên. Backend local có thể dùng provider `fake` cho AI/TTS/phát âm. Giao diện dựa vào `moPhong` của backend để ghi nguồn mô phỏng; nối API không tự chuyển provider sang dịch vụ trả phí.

Các route Next.js practice/notebook/statistics hiện chuyển tiếp backend qua `proxyOrMock`. Fallback đợt 2 chỉ hoạt động khi cấu hình `NEXT_PUBLIC_DOT2_MOCK=enabled`; mặc định tắt. Không thay đổi lựa chọn này trong lần rà soát.

## Những API chưa có màn hình hiện hữu để nối

Backend còn có API thông báo giao dịch, yêu cầu xóa tài khoản, báo cáo nội dung/kiểm duyệt, quản trị hạn mức/dịch vụ, doanh thu, giải thích ngữ cảnh và tạo ảnh AI. Checkout hiện chưa có trang/component tương ứng cho các API này (thiết lập thông báo là màn cài đặt, không phải danh sách thông báo). Chúng không phải phần giao diện mẫu bị bỏ sót trong 9 trang nói trên; nếu triển khai cần thêm UI theo phạm vi riêng.
