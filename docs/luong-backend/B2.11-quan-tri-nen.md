## Khóa / mở tài khoản

```mermaid
sequenceDiagram
    autonumber
    participant FE
    participant C as AdminUserController
    participant S as AdminUserService
    participant A as AccountAdminService
    participant L as AuditService
    participant R as SessionRevoker
    FE->>C: PATCH /admin/users/{id}/status {trangThai, lyDo}
    C->>S: changeStatus(actorId, id, request)
    S->>S: trangThai ∉ {HOAT_DONG, BI_KHOA} → 400; id = actorId → 422
    S->>A: lockForChange(id) — FOR UPDATE vai_tro ADMIN rồi nguoi_dung
    A-->>S: view (hệ thống/không có → 404)
    S->>S: DANG_XOA/CHUA_XAC_THUC → 422; trùng → trả nguyên
    S->>A: countActiveAdmins() (khóa Admin cuối → 422)
    S->>A: changeStatus(id, next)
    S->>L: record(KHOA_TAI_KHOAN | MO_KHOA_TAI_KHOAN, lyDo, {trangThai}, {trangThai})
    S->>S: commit
    S->>R: revokeAll(id) nếu BI_KHOA (Redis lỗi → 503)
    S-->>FE: 200 {…, soPhienDaHuy}
```

Đăng nhập lại khi `BI_KHOA` trả 403 `ACCOUNT_LOCKED` (B1.2, B1.4 đã có).

## Đổi vai trò

```mermaid
sequenceDiagram
    autonumber
    participant FE
    participant C as AdminUserController
    participant S as AdminUserService
    participant A as AccountAdminService
    participant R as SessionRevoker
    FE->>C: PUT /admin/users/{id}/roles {vaiTro[], lyDo}
    C->>S: changeRoles(actorId, id, request, sessionId)
    S->>S: thiếu USER/giá trị lạ/trùng → 400
    S->>A: lockForChange(id)
    S->>S: thu ADMIN của Admin HOAT_DONG cuối → 422; cấp ADMIN cho tài khoản không HOAT_DONG → 422
    S->>A: changeRoles(id, admin)
    S->>S: ghi CAP/THU_QUYEN_QUAN_TRI; commit
    S->>R: revokeAll(id, giữ phiên hiện tại nếu tự bỏ quyền)
    C->>C: banThanMatQuyen → SessionAuthenticator.logout
    C-->>FE: 200 {…, soPhienDaHuy, banThanMatQuyen}
```

Quyền nằm trong phiên (đặt lúc đăng nhập), nên đổi vai trò có hiệu lực ngay nhờ hủy phiên: người bị đổi phải đăng nhập lại.

    S->>S: mã hành động; chuyển nháp/ẩn/hiện thiếu lyDo → 400 (rollback)
    S->>L: record(...)
    FE->>S: DELETE /admin/cards/{id}?version

    S->>D: lock(boTheId)
    S->>S: bộ CONG_KHAI và soThe ≤ 1 → 422

    S->>L: record(XOA_THE_MAU)

## Lỗi

| Status | `code` | Khi nào |
|---|---|---|
| 400 | `VALIDATION_FAILED` | Thiếu/sai `lyDo`, `trangThai`, `vaiTro`, `version`, enum query, ngày nhật ký, khoảng > 366 ngày |
| 401 / 403 | `UNAUTHENTICATED` / `FORBIDDEN` | Chưa đăng nhập / không phải ADMIN (kể cả phiên vừa bị hủy) |
| 404 | `NOT_FOUND` | Người dùng không có/là tài khoản hệ thống; bộ không phải bộ mẫu hoặc đã xóa; thẻ của bộ người học |
| 409 | `VERSION_CONFLICT` | `version` bộ/thẻ cũ |
| 422 | `BUSINESS_RULE` | Quy tắc ở mục c, d, f, g |
| 503 | `DEPENDENCY_DOWN` | Redis lỗi khi hủy phiên (DB đã commit) |
