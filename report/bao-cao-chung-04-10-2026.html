6. Những chỗ khiến trải nghiệm chưa trơn tru

  • Link dẫn tới trang chưa tồn tại: /thu-vien/{id}, /bo-the/{id}/sua, bảo mật, thông báo, quản trị chủ đề.
  • Tìm kiếm và tab yêu thích ở “Bộ của tôi” mới thay đổi state; danh sách chưa được lọc theo lựa chọn.
  • Thư viện: chỉ bộ lọc chủ đề được nối vào query; tìm kiếm, mục tiêu, trình độ, nguồn và sắp xếp chưa điều khiển dữ liệu.
  • Lỗi API dễ bị hiểu thành danh sách rỗng hoặc tải mãi: nhiều trang chưa phân biệt isError, dữ liệu rỗng và đang tải.
  • Lỗi validation chưa hiện đúng dưới ô nhập: BE trả fieldErrors dạng mảng; applyServerErrors lại xử lý như object.
  • Layout ADMIN đặt khác nhánh chứa các trang ADMIN: layout tại app/quan-tri không bao quanh trang trong app/(app)/quan-tri.
  • Mobile: thanh điều hướng dưới còn rỗng và bị ẩn; chưa có điều hướng mobile hoàn chỉnh.
  • Mock không mô phỏng phiên thật: /me luôn trả người dùng demo; đăng nhập không kiểm tra thông tin. Nhiều thao tác không lưu lại dữ liệu.
  • Dữ liệu còn cố định: hồ sơ “Thảo”, ngày cập nhật, submitKey giả và thời gian trả lời 1.500 ms.
  • README FE vẫn là hướng dẫn mẫu; roadmap đánh dấu chưa đồng bộ với phần giao diện đã viết.

7. Cách chạy hiện tại

Các lệnh dưới đây là hướng dẫn, mình chưa chạy chúng trong thư mục FE gốc.

Mở PowerShell thứ nhất để chạy BE nếu chưa chạy:

cd C:\doantotnghiep\khoa_luan_tot_nghiep\backend\k28
docker compose --profile app up -d --build

Mở PowerShell thứ hai:

cd C:\doantotnghiep\khoa_luan_tot_nghiep\frontend
npm ci
$env:NEXT_PUBLIC_API_MOCKING = "disabled"
$env:NEXT_PUBLIC_API_URL = ""
npm run dev -- --port 3000
  • FE: localhost:3000.
  • API/Swagger: localhost:8080/swagger-ui.html.
  • Email xác thực/đặt lại mật khẩu: Mailpit.
  • Để NEXT_PUBLIC_API_URL rỗng thì trình duyệt gọi qua proxy FE; proxy mặc định tới BE cổng 8080.
  • Hiện dev khởi động được nhưng nhiều trang vẫn lỗi. npm run build chưa thành công nên chưa chạy production bằng npm start.
  • Bật NEXT_PUBLIC_API_MOCKING=enabled hiện cũng chưa dùng được vì lỗi bộ mock.

8. Thứ tự xử lý đề nghị

  1. Sửa lỗi cú pháp và bộ mock để FE build được.
  2. Hoàn thiện API client: CSRF, response rỗng, lỗi validation, phiên hết hạn.
  3. Nối đầy đủ phần BE đã bàn giao: tài khoản → hồ sơ → thiết lập → avatar → chủ đề/nhãn.
  4. Đồng bộ schema và phân trang trước khi nối bộ/thẻ; hoàn tất controller BE tương ứng.
  5. Xử lý link thiếu, bộ lọc, lỗi mạng và mobile.
  6. Kiểm thử xuyên suốt: đăng ký → email → đăng nhập → thiết lập → đăng xuất; sau đó mới kiểm thử bộ/thẻ và học/luyện tập.
