# Tài nguyên hình ảnh mockup

| Tệp | Kích thước | Nguồn | Ghi chú |
|---|---|---|---|
| `logo-mark.svg` | 32×32 | Tự vẽ bằng SVG | Ô phiếu chàm, vạch định vị, ô tròn tô chì |
| `logo-mark-inverse.svg` | 32×32 | Tự vẽ bằng SVG | Dùng trên nền chàm đậm (panel đăng nhập) |
| `favicon.svg` | 32×32 | Tự vẽ bằng SVG | Giống `logo-mark.svg` |

Giai đoạn 1 không dùng ảnh chụp. Khi cần ảnh, đặt `.img-slot[data-src]` và thêm một dòng vào bảng này.
